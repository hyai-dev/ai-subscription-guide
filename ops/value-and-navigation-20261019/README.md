**部署状态：两站均已上线并通过公开页面核验。** [上线回执](release.json)记录版本、检查、部署和验收范围。

| --- | --- |

| 订阅与手机卡入口衔接 | [Nano首页](https://nano-banana.lol/)连接订阅目录与手机卡入口；[PayForChat也提供giffgaff教程](https://www.payforchat.com/articles/codex-phone-verification-giffgaff-guide-2026)，不能称独占方案。 |

本批已上线：Nano增加4个按任务继续的导航入口；PayForGPT为4项首页价值补上操作链接，团队采购直达开票客服区域，并提供6项空白需求模板。模板只复制文字，由用户自行补充发送，不收集填写内容、不自动提交、不建单、不扣款。

两站接下来的重点：Nano继续把任务入口与真实可售商品对齐；PayForGPT继续明确商品交付与企业咨询条件。来源到付款、交付的服务端归因，以及真实授权评价，仍待接通或验收。
