# 公开指南维护手册

## 内容发布

主稿在 `docs/`，原创图片和练习在 `assets/`，已审阅文章清单在 `content/publication-manifest.json`。`articles/<稳定ID>.md` 是同一篇教程的归档副本，不按日期重复建稿。README 的最近更新和归档区由标记内的内容自动生成，标记外的任务导航由编辑维护。

```bash
npm test
npm run sync:preview
npm run sync
npm run check
```

预览不写文件；`--check` 检测生成物漂移；`--write` 只写稳定归档、索引、来源链接清单和 README 标记区，不执行 git、不推送。来源、复核日、图片与相对路径校验失败就停止。源文件、图片或文章不存在时不会写成成功。

稿件实际提交并公开后，用完整源提交 SHA 回读：

```bash
npm run verify:public -- --commit <40位源提交SHA>
```

命令匿名读取固定提交的 README、10篇主稿和实际引用图，逐个比较本地字节哈希；另检查相关自有站页面 HTTP200。它不检查真实付款、模型表现或搜索收录，输出保留这些边界。不要把回执中的提交号写回同一次提交来制造无法成立的自引用。

## 价格观察

```bash
npm run prices
```

仅访问 [来源配置](../data/price-sources.json)中的8个公开站点；工具只写 `data/prices/latest.json` 和 `latest.md`，不登录、不下单、不绕过访问限制。第三方 HTML 只当数据解析，不执行其中脚本。

每个观察保留来源、时间、请求/提取状态、原文片段或定位、商品条件与未知项。失败会替换为当前失败记录，不悄悄沿用旧价格。DNS 解析到非公网地址时拒绝请求；某些本机代理会导致这种结果，应记录环境限制，不为“跑通”而关闭检查。页面无法确认或返回挑战页时保留未知。

SIM、发票、税费、交付和资格必须分别有证据，默认未知。观察到价格也不代表同条件可比或已人工审核。库存与最终应付以实际下单页为准。

## 每日 Actions

[daily-sync.yml](../.github/workflows/daily-sync.yml)在每日UTC02:00（北京时间10:00）及手动触发时观察公开价格并同步已审阅文章；push/PR 只做验证。GitHub 调度可能延迟，公开仓库长期无活动也可能停用计划，以实际运行记录为准。[官方 schedule 说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

工作流固定第三方 action 的完整 SHA，默认只读权限；仅本仓库 main 的观察任务获得 contents 写权限，不使用自定义支付/模型密钥。它不运行来历不明的网页脚本、不生成新文章、不自动批准稿件、不填写飞书。发生分支竞争就失败，不强推、不覆盖人工提交；没有生成差异就不创建空提交。

飞书执行看板由获授权的执行方在每批工作完成并公开回读后更新：记录日期、实际改动、提交、运行链接、验证、未完成事项。私人文档全文、用户资料与令牌不进入本仓库。工作流本身不持有飞书权限，因此不能声称每天自动打勾。

## 维护边界

本仓库不是两站的源码或部署仓库。基础密钥扫描、推送保护与一次人工历史审阅不能保证所有敏感资料都能被识别。发现实际泄露应先撤销凭证，再按事实处理历史；普通教程更正保留变更记录，不以重写历史掩盖。
