## 首批实施状态（2026-10-19）

两站商品页的付款、安全材料和会话权限口径已修复，信任页同步说明查单密码只用于本站查单。5x/20x付款前增加方案、交付、周期核对项；实际交付规格仍须由自身商品事实确认。三站5个上下文入口已上线，逐项通过公开HTTP、普通链接、canonical及运营关系核验，见[上线回执](release-20261019.json)。GrokGuide新增的指定链接点击统计沿用同意及DNT/GPC限制；不是成交统计。

后续仍需真实SKU验收、授权步骤图/视频、评价数据接入、来源进入后台订单及服务端付款/交付验收。下面差距表和页面数量是实施前快照，不能代替当前状态或效果数据。

## 先看结论

三个站已有教程、商品与订单基础。下一步应把具体学习问题、方案核对、真实可售商品和售后连接起来，并验证来源是否进入真实订单。公开页面不足以比较双方真实流量、转化率、收入或后台可靠性。

## 实施顺序与验收

1. 修两站商品页的付款、安全材料和SKU规格，核对当前真实商品。
2. 实施5个相关入口，添加运营关系说明、来源参数和正确的商品状态。
3. 补实际界面步骤与短视频，修复评价展示；保留授权与脱敏范围。
4. 在现有同意机制下记录文章/入口/商品点击，将允许的来源字段贯通到建单和服务端确认付款/交付；用受控测试逐段验收。不得将查单密码、完整账号凭证写进URL或统计。
5. 分站观察搜索点击与跨站来源，再核对有效建单、确认付款和交付。收录、排名、转化改善都需要真实后续数据，不能按部署次数或文章数量推定。
